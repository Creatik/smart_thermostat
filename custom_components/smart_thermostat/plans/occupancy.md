# Occupancy + выученный предпрогрев

Предпочтительный путь для всех пользователей (не жёсткие часы в DEFAULTS).

## 1. Кто дома

- `person.*` / tracker — зона home / not_home / «Работа»
- Активность: свет, чайник, motion — OR с person
- Hold N минут после выключения чайника/света

## 2. Учёба графика

При каждом приходе (occupancy False→True) пишем в storage:

```text
arrival_history[] = { timestamp, weekday 0–6, minutes, slot: morning|evening }
```

- morning: 04:00–12:00
- evening: 14:00–24:00
- Храним ~90 дней / до 80 точек

После ≥3 приходов в слоте (сначала тот же weekday, иначе все дни):
**медиана** минут = «обычный приход».

## 3. Предпрогрев

Если никого нет и сейчас в окне  
`[обычный_приход − lead, обычный_приход)`:

- эко снимается
- `t_effective ≥ comfort` → срабатывает обычный target_step_warmup

`learned_preheat_lead_min`: **15…120**, шаг 15 (типично 30 / 45 / 60).  
Default 45. Вкл: `learned_preheat_enable` (default on).

Ручные часы preheat в advanced — запасной вариант, если пользователь задал;  
выученный график имеет приоритет.

## 4. Настройка

1. person.dmitrii_iurevich (+ семья)
2. свет / чайник / motion
3. «Учить график…» + «За сколько минут…»
4. Экономить, когда никого нет

Первые дни только копит приходы; после 3+ точек в слоте начинает греть заранее.
