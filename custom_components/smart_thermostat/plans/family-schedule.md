# Пример: семейный день (один домохозяйство)

Это **пример настройки**, не дефолт интеграции. У других пользователей
другие слоты — поля предпрогрева по умолчанию пустые (выкл.).

Источник примера: HA automation «Управление Smart Thermostat по времени и дням».

## Слоты цели (пример)

| Когда | Цель | Смысл |
|---|---|---|
| Будни 05:00–07:00 | 23°C | Проснулись, оделись, ушли |
| Будни 07:00–18:00 | 18°C | Никого дома |
| Будни 18:00–23:00 | 23°C | Приход с работы/садика |
| Будни 23:00–05:00 | 18°C | Ночь, прохлада, окна открыты без датчиков |
| Выходные 07:00–23:00 | 23°C | Дома днём |
| Выходные 23:00–07:00 | 18°C | Ночь |

## Как включить в ST (Configure → расширенные)

1. `workday_sensor` → свой `binary_sensor.workday_sensor` (если есть)
2. `preheat_morning_ready` = время **начала** утреннего комфорта (здесь 05:00)
3. `preheat_morning_ready_weekend` = 07:00 (или пусто)
4. `preheat_evening_ready` = 18:00 (на выходных вечерний слот не используется)
5. `preheat_lead_min` = 45 → прогрев с 04:15 / 17:15 / 06:15
6. На простой форме: `night_open_windows` = on, если ночью окна без датчиков

Automation по-прежнему задаёт `climate.set_temperature`; ST только
поднимает эффективную цель за lead минут до скачка (инерция радиатора).

Пустые времена предпрогрева = функция полностью выключена для всех остальных.
