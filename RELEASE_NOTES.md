## v2.3.0 — Valve authority, heat delivery и умный прогрев

Минорный релиз поверх v2.2.2. Контур не убивает offset при мёртвой подаче,
диагностика честно отделяет «клапан» от «котла», прогрев и обучение стабильнее.

### ✨ Добавлено
- **Valve authority**: обучение offset не гонит его к ±6, когда клапан уже
  полностью открыт и тепло не течёт, и не хоронит к −6 на эко-«перегреве»
  при закрытом клапане.
- **Сенсор `heat_delivery`** (flowing / absent / unknown): почему не греется —
  контур vs котёл/циркуляция. Анти-ложные гварды: boost, разгон local,
  grace после скачка цели. `last_action = heat_source_absent`.
- **Сервис `clear_arrival_history`** + авто-wipe истории приходов при смене
  `presence_entity` (миграция motion → person.*).
- **Time-слоты** комфорт/сон на устройстве комнаты.

### 🐛 Исправлено
- Скачок расписания считается по сырой цели (`t_target`), не `t_effective` —
  без ложных ±3°C от эко/погоды и спама boost.
- `arrival_warmup` по motion: кулдаун 1 ч + boost только при реальном недогреве.

### 🔧 Изменено
- Обучение: восстановление `learn_rate_slow`, выход из насыщения (deep_against),
  pending-аккумулятор дробных поправок.
- UI: короткая форма + advanced; планы в `plans/`; 100+ юнит-тестов.

### 📦 Установка / обновление
- Обновление через HACS → **Smart Thermostat** → **Update**, затем **перезапуск
  Home Assistant** (reload entry не подхватывает новый `.py`).

## v2.2.2 — Улучшения точности управления и обучения offset

Патч-релиз поверх v2.2.1. Доработано ядро управления для более точного удержания
температуры и стабильного обучения смещения.

### ✨ Улучшено
- **Цикл управления** (`controller.py`): доработка обработки режимов, обучения offset
  и удержания в мёртвой зоне — меньше перегрев/недогрев, стабильный выход на цель.
- **Хранилище** (`storage.py`): расширены истории и обучаемые данные
  (offset, preset, heating_rate) с debounce-сохранением.
- **Сопутствующие правки** в `__init__.py`, `climate.py`, `config_flow.py`, `const.py`,
  `inputs.py`, `pid.py`, `sensor.py`.

### 📋 Планы работ
- Добавлены `plans/precision-improvements.md` и `plans/valve-not-closing-fix.md` —
  документация по улучшениям точности и истории исправлений клапана.

### 📦 Установка / обновление
- Обновление через HACS → **Smart Thermostat** → **Update**, затем перезапуск Home Assistant.

## v2.2.1 — Исправления стабильности и перевода

Патч-релиз поверх v2.2. Исправлены проблемы, возникавшие при настройке через UI.

### 🐛 Исправлено
- **Ошибка при открытии настроек** «Entity None is neither a valid entity ID nor a valid
  UUID» — для сущностей погоды, наружного датчика и влажности значение по умолчанию
  теперь корректно обрабатывается (`vol.UNDEFINED` вместо `None`).
- **Отсутствующие переводы** опций в русской локализации: добавлены `outdoor_sensor_entity`,
  `min_on_sec`, `min_off_sec`, `valve_exercise_days`, `valve_exercise_sec`,
  `weather_base_temp`, `weather_max_comp`, `eco_enable`, `cooldown_reduction_factor`.
- **Валидация hassfest**: переводы пресетов перенесены в корректный ключ `state`.

### 📦 Установка / обновление
- Обновление через HACS → **Smart Thermostat** → **Update**, затем перезапуск Home Assistant.
