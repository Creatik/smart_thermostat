## v2.2 — Пресеты, анти-дребезг, мягкая посадка, valve exercise

### ✨ Что нового

#### 🎚️ Пресеты Comfort / Eco / Away / Sleep
- Быстрое переключение целевой температуры через нативное свойство `preset_mode` виртуального термостата.
- Каждая температура настраивается в UI: `preset_comfort_temp`, `preset_eco_temp`,
  `preset_away_temp`, `preset_sleep_temp`.
- Ручная установка температуры сбрасывает активный пресет в «none».
- Работает с дашбордами, автоматизациями и HomeKit без доп. сущностей.

#### 🔄 Анти-дребезг
- Новые опции `min_on_sec` / `min_off_sec` — минимальное время удержания состояния
  TRV перед сменой направления. Защищает клапан от частых команд.

#### 🎯 Прогнозная мягкая посадка
- Отсечка перегрева при подходе к целевой температуре — плавное, без «перелёта».

#### 🔧 Valve exercise
- Автопрокрутка клапана для предотвращения залипания:
  `valve_exercise_days` (период) и `valve_exercise_sec` (длительность).

### 🐛 Исправления
- Корректные значения по умолчанию для сущностей в настройках (устранена ошибка
  «Entity None is neither a valid entity ID nor a valid UUID»).
- Добавлены недостающие переводы опций (`outdoor_sensor_entity` и др.).
- Преобразование пресетов для hassfest (перевод в ключе `state`).

### 🛠️ Установка / обновление
- Обновление через HACS → **Smart Thermostat** → **Update**, затем перезапуск Home Assistant.
